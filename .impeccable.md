## Design Context

### Users

The primary user is the creator, using GEXLab as a personal premarket trading
briefing tool. The core job is to quickly understand volatility, expected move
size, overnight context, options structure, and likely reaction zones before
making a trading plan.

### Brand Personality

Calm, precise, institutional. The interface should create confidence through
clear hierarchy and measured feedback, not excitement or urgency.

### Aesthetic Direction

Support both the existing Warm Ledger light theme and Ink Ledger dark theme.
Keep the editorial/institutional visual language, with restrained motion that
helps users track relationships between levels, ranges, and state changes.
SVG charts and data marks may animate as analytical objects, never as decoration
that competes with live values. Reduced-motion support is required.

### Design Principles

- Animate state changes and analytical relationships, not every element.
- Make premarket decisions scannable: values settle quickly and remain legible.
- Use calm, precise easing and avoid bounce, elastic motion, and novelty effects.
- Preserve the meaning of light/dark theme tokens and accessible contrast.
- Treat SVG geometry as information: reveal paths, bands, levels, and markers in
  the same order the user reads them.
